综合演示

使用命令式 API 构建的完整 Canvas UI 演示，包含计数器、Todo 列表、布局、动画、响应式系统等功能。

🎨 命令式 API — 全功能展示

通过 createApp、CanvasNode、TextNode、ButtonNode 等 API 直接构建 Canvas UI。 支持 Flexbox 布局、事件绑定、hover 效果、响应式数据等。

📦 Imperative API 🖱️ 点击按钮交互 · 悬停查看效果

.vuvas 单文件组件

像写 Vue 一样写 Canvas 组件。支持 <template>、<script setup>、<style> 三段式结构， 内置 v-if、v-for、@click 等模板语法。

📦 SFC 组件 — 声明式 UI

通过 createVuvasApp(App).mount('#app') 挂载 .vuvas 组件， 享受 Vue 风格的开发体验。

📄 .vuvas SFC 🖱️ 点击按钮交互

响应式系统

基于 Proxy 的响应式系统，支持 ref、computed、watchEffect， 数据变化自动触发 UI 更新。

⚡ ref + computed + watchEffect

修改 ref 值后，computed 自动重新计算，watchEffect 自动执行副作用更新 Canvas UI。

⚡ Reactivity 点击按钮修改温度，观察自动更新

Flexbox 布局

完整的 Flexbox 布局引擎，支持 flexDirection、justifyContent、alignItems、gap、flexGrow 等属性。

📐 布局演示

展示 row/column 方向、对齐方式、嵌套布局、渐变背景、边框样式等。

📐 Flexbox 悬停在彩色方块上查看 hover 效果

事件系统

支持 click、hover、mousedown、mouseup 等事件， 精确的命中检测 + 事件冒泡机制。

🎯 事件交互

计数器按钮点击、Todo 项切换、hover 样式变化等交互效果。

🎯 Events 点击按钮和 Todo 项体验交互

动画

基于 requestAnimationFrame 的动画系统，支持进度条、过渡效果等。

🚀 动画进度条

点击"开始"按钮启动动画，支持暂停和重置。

🚀 Animation 点击开始/暂停/重置控制动画
